# Fire_Detection_System
To view this project on colab:
(https://colab.research.google.com/github/sangam20607/Fire_Detection_System/blob/main/ann_project.ipynb)

Overview
This project is an image classification system that detects whether an image contains fire or non-fire elements using Machine Learning.
The model is trained on fire and non-fire image datasets to help identify fire hazards quickly and accurately.

Features:
Classifies images as Fire or Non-Fire
Image-based fire detection
Simple and efficient model
Fast prediction system

Technologies Used:
Python
Google Colab
TensorFlow / Keras
OpenCV
NumPy
Matplotlib

Working:
The dataset containing fire and non-fire images is loaded.
Images are preprocessed and resized.
The model is trained using image classification techniques.
The trained model predicts whether the input image contains fire or not.

Applications:
Forest fire monitoring
Smart surveillance systems
Industrial safety systems
Emergency detection systems

Conclusion:
The project demonstrates how Machine Learning can be used for basic fire detection through image classification, helping improve safety and early hazard detection.
